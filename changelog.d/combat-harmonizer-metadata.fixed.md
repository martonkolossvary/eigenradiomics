`ComBatHarmonizer` now aligns a `batch` Series and a `covariates` DataFrame to X by index; arrays stay positional. Missing batch labels, text collisions of batch labels, missing fitted covariate columns and non-finite covariates at transform now raise (a missing column was filled with 0). A feature with zero pooled within-batch variance, or non-finite batch parameters, now raises instead of making every output value NaN.
