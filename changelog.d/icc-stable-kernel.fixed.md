ICC(2,1) now uses one numerically stable kernel for the point estimate and the bootstrap. The kernel subtracts a common origin, rescales by a power of two, and sums the squared residuals directly. An exactly constant feature (for example 64 values of 0.1) now gives NaN with status "constant", and identical readers at a large offset now give ICC 1. The new `precision_limited` column marks features that span fewer than about 1000 floating-point steps.
