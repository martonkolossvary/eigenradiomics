`WGCNAReducer` now keeps constant features out of the network and marks them unassigned ("grey"), as the warning says. Unassigned features are now "grey" (PyWGCNA 2.2.1 named them "black"). In `missing_strategy="pairwise"`, a pair with fewer than 3 shared samples gets no edge; before, a signed network gave it adjacency 0.5**power. For the "zero", "floor" and "median" strategies, the eigengene loadings now use the same imputed matrix as `transform`.
